# Executor self-host specifics

Single container, whole product over one libSQL file: DB at `/data/data.db` in named volume `<appName>_executor-data`. Users/passwords are better-auth's `account` table (`providerId='credential'`) as `${salt}:${hex(scrypt(pw, salt))}` with salt = 16 random bytes hex, `N=16384, r=16, p=1, dkLen=64`, and the salt is used as its **hex string** (UTF-8 bytes), not decoded. Node's `crypto.scryptSync` reproduces it exactly — verify against `verifyPassword` from `@better-auth/utils` before writing anything. `EXECUTOR_BOOTSTRAP_ADMIN_EMAIL/PASSWORD` are **first-boot only**: `seedOrgAndAdmin` returns early once an `organization` row exists, so they cannot reset an existing account. There is no self-serve password reset in the UI and no email provider configured by default.
